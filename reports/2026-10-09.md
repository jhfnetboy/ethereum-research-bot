## 今日要点
1. **断言语义**：EIP-7906 合并“断言失败回滚执行体”，并规定 TXDIFF 与 POST_TX 回滚在 BAL 中如何记录。
2. **frame 交易结构**：EIP-8141 在 Behavior 部分定义验证前缀和执行体；EIP-8077 为 frame 交易定义 source 和 nonce。
3. **keyed nonce**：EIP-8250 PR 提议 keyed nonce 改为一次性 spent 标记；EIP-8130 PR 简化 Keystore。
4. **ERC-8441**：ML-KEM-768 与 secp256k1 ECDH 组合的隐形地址，花费方式不变，沿用已部署的 ERC-5564 和 ERC-6538 合约。

## 重点话题

### 1. Frame 交易与断言：执行语义落定
**发生了什么**
- [EIP-8141：在 Behavior 下定义验证前缀和执行体](https://github.com/ethereum/EIPs/pull/12471) 合并，[并命名 TXPARAM、FRAMEPARAM、SIGPARAM 参数](https://github.com/ethereum/EIPs/pull/12469)（spencer-tb）。
- EIP-7906：[断言失败会回滚执行体](https://github.com/ethereum/EIPs/pull/12466)（danceratopz）、[TXDIFF 与 POST_TX 回滚的 BAL 记录方式](https://github.com/ethereum/EIPs/pull/12463)（forshtat）均已合并；[通过 EIP-8141 的验证前缀说明 POST_TX 回滚点](https://github.com/ethereum/EIPs/pull/12472) 提交。
- [EIP-8250：把 keyed nonce 改为一次性 spent 标记](https://github.com/ethereum/EIPs/pull/12467) 提交（nerolation）；[EIP-8130：简化 Keystore](https://github.com/ethereum/EIPs/pull/12462) 提交（chunter-cb）。
- [EIP-8077：为 frame 交易定义 source 和 nonce](https://github.com/ethereum/EIPs/pull/12139) 合并，这是“交易公告附带 nonce”的网络层 EIP。

**为什么重要**
- 验证前缀与执行体分开，意味着验证阶段（签名、付费）和执行阶段的失败可以分别处理；断言失败只回滚执行体，不影响验证阶段。keyed nonce 变成一次性标记后更像隐私池里的 nullifier，这类标记的存储成本会受 Glamsterdam 状态定价影响。

### 2. 隐私：后量子隐形地址与私密稳定币
**发生了什么**
- [Magicians：ERC-8441 混合后量子隐形地址方案](https://ethereum-magicians.org/t/erc-8441-hybrid-post-quantum-stealth-address-scheme/29923) 11:18（namncc，[PR](https://github.com/ethereum/ERCs/pull/2059)）。它在 ERC-5564 中定义 schemeId 3：支付密钥由 ML-KEM-768 封装与 secp256k1 ECDH 组合而成，只要 ML-KEM-768 安全，未来有量子计算机的对手也无法从公告日志看出谁收了款。每个隐形地址仍是普通 secp256k1 EOA，不需要协议改动和新合约。
- [ethresear.ch：以太坊上的私密稳定币](https://ethresear.ch/t/private-stablecoin-on-ethereum/26140) 19:40，以 USDC/USDT 为背书，由合约强制铸造赎回，交易数据保密或与身份不可关联。
- [Aztec：Nyx 让你在 Rabby 里私密收发，并在 Aave 上无关联地赚收益](https://x.com/aztecnetwork/status/2108258672745070621) 01:10；[Aztec：私密推理覆盖支付、身份、内容三层隐私](https://x.com/aztecnetwork/status/2108558518534177111) 21:01。

**为什么重要**
- ERC-8441 只保护“收款人是谁”免受将来的量子回溯，花费仍依赖 secp256k1，所以它解决的是“先收集、后解密”的隐私风险，不是资金安全。钱包现在就能接入。
