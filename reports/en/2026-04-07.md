## Key topics

### 1. Accounts: Sandboxed Smart Wallet
**What happened**
- [Add ERC: Sandboxed Smart Wallet](https://github.com/ethereum/ERCs/pull/1609) (PowerStream3604), merged after submission on March 19, defining sandboxed wallet interfaces for secure agent automation; [EIP-8130: fix sentinel addresses](https://github.com/ethereum/EIPs/pull/11492) (chunter-cb), submitted.

**Why it matters**
- For accounts: with the agent wallet standard merged, wallets and agent frameworks can implement bounded permissions against one interface.

### 2. Scaling: blocks in blobs
**What happened**
- [ethresear.ch: Blocks Are Dead. Long Live Blobs](https://ethresear.ch/t/blocks-are-dead-long-live-blobs/24611), 19:00; [nero_eth: zkEVMs paired with blobs and DAS scale data too; EIP-8142 moves execution payloads into blobs so validators sample instead of downloading everything](https://x.com/nero_eth/status/2041544589320880199), 22:52.

**Why it matters**
- For transactions: once execution data also goes through data availability sampling, gas limit increases are no longer bound by each node's download bandwidth.
