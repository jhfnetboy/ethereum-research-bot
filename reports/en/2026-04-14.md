## Key topics

### 1. Accounts: post-quantum keys and the native AA call
**What happened**
- [Magicians: ERC-8231 Post-Quantum Key Registry](https://ethereum-magicians.org/t/erc-8231-post-quantum-key-registry/28235), 16:42 (Valisthea), a standard interface for onchain registration, rotation, revocation and migration of ML-KEM (FIPS 203), ML-DSA (FIPS 204) and SLH-DSA (FIPS 205) keys, not an immediate replacement for secp256k1; the [ERC PR](https://github.com/ethereum/ERCs/pull/1684) was submitted.
- [Native Account Abstraction #1 agenda](https://ethereum-magicians.org/t/native-account-abstraction-1-april-22-2026/28227), 02:24, with the call set for April 22.
- [EIP-8130: fix sentinel addresses](https://github.com/ethereum/EIPs/pull/11492) (chunter-cb), merged.
- [binji_x: preparing to explain Kohaku and post-quantum Ethereum](https://x.com/binji_x/status/2043993177963565299), 17:02.

**Why it matters**
- For accounts: a dedicated native AA breakout shows Hegotá needs to converge among designs such as EIP-8141 and EIP-8130; registration and rotation interfaces for post-quantum keys are what wallets and apps will rely on together when accounts switch signature schemes.

### 2. State and gas: EIP-8188
**What happened**
- [Magicians: EIP-8188 Last-Written Block for Accounts and Slots](https://ethereum-magicians.org/t/eip8188-last-written-block-for-accounts-and-slots/28234), 14:21 (weiihann), recording the block number of the last write to every account and storage slot, a first step toward hot and cold state separation.
- [EIP-8037: clarify that spillover state gas counts as state gas](https://github.com/ethereum/EIPs/pull/11522) (qu0b), merged.

**Why it matters**
- For users: knowing which state has gone unwritten for a long time is what allows hot and cold state to be priced or handled differently later, which decides who bears the long term cost of state growth.
