## Key topics

### 1. Post-quantum signatures and frame transaction implementation
**What happened**
- [New EIP: precompiles for ML-DSA verification](https://github.com/ethereum/EIPs/pull/12048) (shemnon), merged as a Draft: a "just the FIPS" set of precompiles for all ML-DSA parameter sets.
- [ethrex: EIP-8141 was SFI'd in the last ACDE](https://x.com/ethrex_client/status/2094781529817768050), 20:36; the team has been building a reference implementation on ethrex since 8141 was first proposed as a headliner, and other clients have since picked frames up.
- [EIP-8141: remove a redundant check for a frame's state gas limit](https://github.com/ethereum/EIPs/pull/12276) (raxhvl), submitted: total gas is already bounded by `total_frame_gas < 2**64`, so a separate check on the state gas component is redundant, and the boundary is made consistent as `< 2**64`.
- Frame Tx Breakout #3 was held in the evening, on client progress and AA proposal updates, with no notes to cite.

**Why it matters**
- For wallets and account contracts: if the ML-DSA precompiles land, 8141 accounts could verify NIST-standard post-quantum signatures onchain through a precompile instead of implementing lattice cryptography in EVM bytecode.
