## Key topics

### 1. Accounts: post-quantum key storage
**What happened**
- [Magicians: Storage of non-recoverable account keys on chain](https://ethereum-magicians.org/t/storage-of-non-recoverable-account-keys-on-chain/27361) (SirSpudlington), 04:54: most asymmetric schemes cannot recover the public key from a signature, so post-quantum migration must either attach the key to every transaction or store it in a contract, assuming bundling with EIP-7932.

**Why it matters**
- For accounts and gas: post-quantum keys are large, and attaching one to every transaction adds heavy calldata cost, so registering once onchain lowers the cost of every later transaction.

### 2. Transaction safety: address poisoning
**What happened**
- [Magicians: ERC-8117 Compressed Display Format for EVM Addresses](https://ethereum-magicians.org/t/erc-8117-compressed-display-format-for-evm-addresses/27360) (xinbenlv), 04:09, later renamed an anti poisoning compact address format; the [PR](https://github.com/ethereum/ERCs/pull/1438) was submitted.

**Why it matters**
- For transactions: address poisoning exploits users checking only the first and last characters, and a standard compact format makes lookalike addresses harder to pass.
