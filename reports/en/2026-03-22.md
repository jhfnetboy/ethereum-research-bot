## Key topics

### 1. Accounts and payments: agent settlement
**What happened**
- [Add ERC: Agent Offchain Conditional Settlement](https://github.com/ethereum/ERCs/pull/1614) (xrqin), submitted; [Magicians thread ERC-8203](https://ethereum-magicians.org/t/erc-8203-agent-off-chain-conditional-settlement-extension-interface/28041), 15:09: existing agent ERCs cover identity, accounts, permissions and payment signaling but no common settlement layer for high frequency machine to machine interaction, which this fills with state channel style conditional settlement.

**Why it matters**
- For transactions: agent micropayments are unaffordable if each settles onchain, and off chain settlement with an onchain fallback cuts it to opening and closing a channel.
