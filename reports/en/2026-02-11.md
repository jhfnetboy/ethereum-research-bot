## Key topics

### 1. Privacy: ZK API usage credits
**What happened**
- [ethresear.ch: ZK API Usage Credits, LLMs and Beyond](https://ethresear.ch/t/zk-api-usage-credits-llms-and-beyond/24104) (dcrapis and VitalikButerin), 20:34: API metering struggles to be private, secure and efficient at once; Web2 auth ties each request to a real identity, and paying onchain per request is slow, costly and exposes the transaction graph, so the design uses zero knowledge prepaid credits.

**Why it matters**
- For privacy: what users send to LLMs is often their most sensitive data, and the payment method decides whether requests can be separated from identity, a direct use of Ethereum privacy tools in AI.
