## Key topics

### 1. Native AA and privacy: commit reveal frames
**What happened**
- [Add EIP: Commit-Reveal Transaction Frames](https://github.com/ethereum/EIPs/pull/11466) (forshtat), submitted; per the [Magicians thread EIP-8209](https://ethereum-magicians.org/t/eip-8209-commit-reveal-transaction-frames/28105), it targets the long discussed inclusion time privacy problem by committing to and later revealing transaction contents inside EIP-8141 frame transactions.

**Why it matters**
- For transactions: unlike LUCID's threshold encryption, commit reveal needs no key committee at the cost of an extra step, giving frame transactions another anti MEV option.

### 2. Contracts and execution
**What happened**
- [Add EIP: Increase Maximum Contract Size to 64KiB](https://github.com/ethereum/EIPs/pull/11462) (Giulio2002), submitted: code size from 24KiB to 64KiB and initcode from 48KiB to 128KiB, keeping EIP-3860's 2:1 ratio with INITCODE_WORD_COST unchanged.
- [ladislaus0x: EIP-8025 optional zkEVM proofs need execution layer work too, including a proven stateless guest program and a standard data package for stateless validation](https://x.com/ladislaus0x/status/2038019146718339228), 05:23.
