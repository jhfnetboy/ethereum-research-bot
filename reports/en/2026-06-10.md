## Key topics

### 1. 7702 authorizations and 8130 accounts
**What happened**
- [EIP-8037: improve EIP-7702 authorization gas accounting](https://github.com/ethereum/EIPs/pull/11715) (rjl493456442), merged, covering corner cases such as cancelling an authorization within the same transaction. State gas now matches the net state changes from authorizations, except that clearing a pre-existing authorization is intentionally not refunded.
- [EIP-8130: `authenticateActor` returns scope, policyType, policyTarget](https://github.com/ethereum/EIPs/pull/11794) (chunter-cb), submitted. It used to return only the scope byte; now one call surfaces the resolved actor's full authorization surface. [EIP-8130: RLP ABI correction](https://github.com/ethereum/EIPs/pull/11791), submitted and merged.
- [Magicians: ERC-8168 Payer Services for ERC-8130](https://ethereum-magicians.org/t/erc-8168-payer-services-for-erc-8130/28762), 22:48 (chunter), for an ERC on an 8130 payer web service capability.

**Why it matters**
- For wallets: 7702 authorization gas is no longer consumed at the worst case, so batched authorizations and revocations cost more predictably. For 8130: the payer is a separate actor role, and standardizing payer services lets gas sponsorship be discovered and called like a service.

### 2. State tiering pricing
**What happened**
- [New EIP: State Tiering by Periods](https://github.com/ethereum/EIPs/pull/11788) (weiihann), submitted, with a [Magicians thread](https://ethereum-magicians.org/t/eip-8295-state-tiering-by-periods/28763) at 23:40; this is EIP-8295. It reads the `last_written_block` recorded by EIP-8188, so writing to state untouched for roughly a year costs more than writing to recently mutated state; reads are unchanged and nothing is removed or expired. [Fixed-Cutoff State Tiering](https://github.com/ethereum/EIPs/pull/11790) (EIP-8296) was also submitted.
- [EIP-8188: last-written block for accounts and slots](https://github.com/ethereum/EIPs/pull/11784), merged.

**Why it matters**
- For long inactive accounts: writing old balances or storage slots again becomes more expensive, which affects the gas cost of waking up dormant accounts.
