## Key topics

### 1. Gas: the state gas refund question
**What happened**
- [EIP-8037: refund state gas on all frame failures including top level](https://github.com/ethereum/EIPs/pull/11476) (qu0b), submitted: an alternative to the previous day's PR 11468 with identical child frame handling, differing in that top level failure resets execution_state_gas_used to zero so the sender gets a full state gas refund.
- [EIP-7708: add CREATE and CREATE2 to the transfer log list](https://github.com/ethereum/EIPs/pull/11474) (s1na), submitted, since creates differ enough from CALLs to be listed explicitly.

**Why it matters**
- For gas: a failed transaction writes no state, so a full refund fits state gas's purpose of charging for long term storage, while keeping the charge stops failed transactions from consuming the block's state budget.

### 2. Accounts: Safe's post-quantum path
**What happened**
- [koeppelmann: Safe already has a quantum security path that needs no migration; users keep their Safe and rotate the owner to a quantum secure hash based signer, now being made production ready](https://x.com/koeppelmann/status/2039095395419148292), 04:40.

**Why it matters**
- For accounts: this is a key advantage of contract accounts over EOAs, with a swappable signature scheme and no change of address or assets, while EOAs rely on EIP-8141 default code or migration.
