## Key topics

### 1. Native AA and privacy: keyed nonces
**What happened**
- [Add EIP: Keyed Nonces for Frame Transactions](https://github.com/ethereum/EIPs/pull/11598) (soispoke), submitted: lets one EIP-8141 sender run multiple independent nonce sequences in parallel instead of a single linear queue (the first version, [#11597](https://github.com/ethereum/EIPs/pull/11597), was closed).
- [nero_eth: Ethereum is turning privacy into a first class primitive; with frame transactions (EIP-8141) and 2D nonces, fees can be paid from the withdrawal itself, with no third party relayer or doxxed account](https://x.com/nero_eth/status/2051266642039001142), 18:44.
- [soispoke: people are not ready for the Ethereum privacy arc](https://x.com/soispoke/status/2051284315267338716), 19:54.
- [Magicians: app scoped nonce lanes for ERC-4337 accounts (draft)](https://ethereum-magicians.org/t/draft-app-scoped-nonce-lanes-for-erc-4337-accounts/28424), 10:33.

**Why it matters**
- For privacy: privacy pool users share one sender address to avoid revealing identity, and a single nonce lets one delayed transaction block everyone; independent sequences fix concurrency, and because frame transactions can pay gas from withdrawn funds, users no longer need a doxxed account to fund gas or a relayer.

### 2. Transactions and gas: merges and new proposals
**What happened**
- [EIP-8037: fixed CPSB plus frame accounting](https://github.com/ethereum/EIPs/pull/11573) (misilva73), merged.
- [EIP-8130: prevent cross sender payer signature replay](https://github.com/ethereum/EIPs/pull/11591) (pochenai), merged.
- [EIP-7708: Soldøgn Interop breakout decisions](https://github.com/ethereum/EIPs/pull/11596) (Carsons-Eels), submitted and merged: EIP-7708 will not be extended to priority fees, base fee burn or withdrawals, and the rationale is documented.
- [Add EIP: CREATE2 redeployment for delegation indicators](https://github.com/ethereum/EIPs/pull/11599) (chunter-cb), submitted: deploys EIP-7702 style delegation indicators through contract creation, with a narrow CREATE2 collision exception that only lets a delegation indicator replace another one.
- [EIP-7981: simplify spec](https://github.com/ethereum/EIPs/pull/11600) (chfast), submitted, behavior unchanged.

**Why it matters**
- For users: with EIP-8037 merged, Glamsterdam state gas uses a fixed per byte cost; with EIP-7708's scope settled, wallets can build against a defined set of ETH transfer logs.
