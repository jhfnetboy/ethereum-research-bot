### 2. Native AA: EIP-8141 and the signature registry
**What happened**
- [EIP-8141: migrate EOA default code to the EIP-7932 registry](https://github.com/ethereum/EIPs/pull/11408) (SirSpudlington), submitted: one reason is that EIP-8141's P256 support overlooks that EIP-7951 does not handle signature malleability.
- [EIP-8141: add derekchiang as a coauthor](https://github.com/ethereum/EIPs/pull/11406) (derekchiang), submitted and merged; [EIP-7906: rationale](https://github.com/ethereum/EIPs/pull/11405) (forshtat), submitted and merged.

**Why it matters**
- For accounts: routing default code through one registry lets passkeys (P256) and future post-quantum signatures plug in under consistent rules.
