### 2. Intrinsic gas and multidimensional pricing
**What happened**
- [EIP-2780: clarify OOG handling for top-level gas charges](https://github.com/ethereum/EIPs/pull/11834) (misilva73), submitted and merged: when a transaction has enough gas for its intrinsic cost but not for the top-level charges applied during execution (the new-account state charge, or the extra `COLD_ACCOUNT_ACCESS` for a delegated recipient), since these are evaluated after EIP-7702 authorizations and need state access, it is treated as an exceptional halt: the transaction is included and reverted, not invalidated, and validity stays decidable without state.
- [EIP-2780: account for the EIP-7623 calldata floor base](https://github.com/ethereum/EIPs/pull/11836), submitted and merged; [EIP-2780: require EIP-7523 instead of EIP-161](https://github.com/ethereum/EIPs/pull/11828), merged.
- [EIP-7999: add data and state resources, simplify gas accounting](https://github.com/ethereum/EIPs/pull/11835) (misilva73), submitted, expanding from three resource dimensions to four: a data resource priced from EIP-8131 content bytes and EIP-8279 BAL bytes with a flat `DATA_GAS_LIMIT = 60M`, dropping EIP-7623 floor pricing, and state growth as a separately priced dimension.
- [EIP-8037: explanation of the 101 byte count](https://github.com/ethereum/EIPs/pull/11818), merged; [EIP-8279 explicit BAL data metering](https://github.com/ethereum/EIPs/pull/11819), merged; [Magicians: EIP-8311 Increase Calldata Floor Cost to 96](https://ethereum-magicians.org/t/eip-8311-increase-calldata-floor-cost-to-96/28860), 19:16.

**Why it matters**
- For 7702 wallets: sending to an address that has delegated to code costs an extra cold access, and a wallet that estimates gas as for a plain transfer will see the transaction included, reverted and charged. If multidimensional pricing ships, data and state growth get their own prices, so transactions with large signatures and transactions writing new state no longer crowd each other out.
