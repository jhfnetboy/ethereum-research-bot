## Key topics

### 1. Propagating frame transactions and privacy apps
**What happened**
- [New ERC: frame transaction alternative mempools](https://github.com/ethereum/ERCs/pull/2028) (forshtat). EIP-8141's public mempool limits validation gas, payers and pending transactions per sender, so transactions that do not meet these rules need another channel, similar to ERC-4337's alternative mempools.
- [ethbeat: link privacy against the network observer is now green for Privacy Pools](https://x.com/ethbeat_org/status/2102745913110167751), 20:04, the result of two recent frontend fixes, the latest being custom RPC support.
- [StarkWare: private swaps live on Ekubo, using the same liquidity as public swaps](https://x.com/StarkWareLtd/status/2102675296520634537), 15:23.

**Why it matters**
- Privacy apps' validation budgets may exceed the public mempool cap (the September 3 benchmark put it at 211,828 gas against 100k), and alternative mempools are where they can land before any protocol change. For users, running your own RPC keeps the RPC provider from linking your IP to your transactions.

### 2. Fast confirmation and hashes
**What happened**
- [Julian Ma: FCR may soon be relied on for millions of dollars in bridging volume, and here is how it stays secure](https://x.com/_julianma/status/2102773912585011370), 21:55; FCR is an algorithm clients run locally rather than something read from the chain like finality, which makes it more complex.
- [ethresear.ch: post-Poseidon hash function variants for Ethereum](https://ethresear.ch/t/post-poseidon-hash-function-variants-for-ethereum/26071), 16:50 (khovratovich). With Flock as a PQ proof system for binary circuits, protocols whose computation is proven no longer require circuit-friendly hashes, but the choice still has to weigh mass uses such as the consensus layer's XMSS signatures.
- [ethresear.ch: EIP-8411 payload segmentation under the Shadow simulator](https://ethresear.ch/t/eip-8411-payload-segmentation-under-the-shadow-simulator/26070), 14:16, where every segmented variant beats the whole message in every configuration.

**Why it matters**
- Once bridges rely on FCR, L1-to-L2 deposits shrink from about 13 minutes to seconds; the security model must be clear before bridges will use it.
