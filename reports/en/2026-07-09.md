## Key topics

### 1. Accounts and transaction assertions
**What happened**
- [EIP-8130: renumber AA transaction types and add an eth_call/eth_estimateGas RPC extension](https://github.com/ethereum/EIPs/pull/11903), merged.
- [EIP-7906: add per-address TXDIFF views and account change flags](https://github.com/ethereum/EIPs/pull/11900) (forshtat), merged, extending the `TXDIFF` opcode with params `0x06` to `0x0A` so per-contract questions such as "did it change?" and "did it emit?" can be answered directly.
- [EIP-7928: exclude the recipient when a runtime halt precedes its access](https://github.com/ethereum/EIPs/pull/11902) (nerolation), merged; [EIP-2780: clarifications](https://github.com/ethereum/EIPs/pull/11891) and [alignment with recent changes](https://github.com/ethereum/EIPs/pull/11906), merged.

**Why it matters**
- For wallets: per-address TXDIFF views let POST_TX assertions check directly that only certain contracts were touched, groundwork for bringing trustworthy clear signing and transaction simulation into the protocol.

### 2. Security and privacy
**What happened**
- [EF blog: the triage is the product, running AI agents against Ethereum's protocol code](https://blog.ethereum.org/en/2026/07/09/triage-is-the-product) (Nikos Baxevanis), with the [EF post](https://x.com/ethereumfndn/status/2075248337821798657) at 22:58. The Protocol Security team runs coordinated AI agents against systems software, cryptographic code and contracts and found real bugs; one now public is a remotely triggerable panic in libp2p's gossipsub, CVE-2026-34219. The surprise was how much of the work went into telling real bugs from ones that only looked real.
- [ameensol: building Privacy Pools v2](https://x.com/ameensol/status/2075248531875762602), 22:59: in shielded pools each deposit gets an individually approved ID that can still be revoked later (unlike Railgun's one-time PPOI), and every private transfer carries a `deposit_ID`.
- [L2BEAT: Zama confidential tokens added to the privacy dashboard](https://x.com/ethbeat_org/status/2075208333959581711), 20:19.

**Why it matters**
- For client teams: AI agents can already find real vulnerabilities in protocol code, but results are only usable after rigorous triage. For privacy pools: revocable per-deposit compliance IDs are one design for meeting compliance while keeping privacy.
