## Key topics

### 1. Gas accounting and structure in the frame transaction family
**What happened**
- [EIP-8141: apply charged_gas to fee settlement](https://github.com/ethereum/EIPs/pull/11969) (soispoke), submitted. 8141 defined frame gas limits, a transaction-level EIP-3529 refund and the EIP-7623 calldata floor but did not connect them consistently: `charged_gas` still referenced `total_gas_used`, and fee settlement used the older `tx_fee` model without reconciling the payer's maximum fee escrow. The PR computes unused gas from the ordered frame receipts, applies the refund before the floor to get `charged_gas`, uses it for block gas accounting and receipt `cumulative_gas_used`, reserves `tx_gas_limit` before execution and returns the difference to the block gas pool.
- [EIP-8250: align transaction introspection assignments](https://github.com/ethereum/EIPs/pull/11966) (soispoke), submitted and merged: 8250 assigned `TXPARAM_NONCE_KEY_0` to `0x0B`, which 8141 already uses for `len(signatures)`, so it moves to `0x10`, and nonce consumption and rollback wording follows 8141's current `payer` and atomic batch model.
- [EIP-8272: resolve the RECENTROOTREFLOAD opcode collision](https://github.com/ethereum/EIPs/pull/11967), submitted, moving it from `0xB4`, already 8141's `SIGPARAM`, to `0xB5`. [EIP-8250: make keyed nonce changes additive](https://github.com/ethereum/EIPs/pull/11968) and [EIP-8272: make recent root changes additive](https://github.com/ethereum/EIPs/pull/11970), submitted, so both are expressed only as changes to 8141. [EIP-8141: clarify decoding, signing and activation](https://github.com/ethereum/EIPs/pull/11971), submitted, defining the payload's RLP shape and applying EIP-7951 validation rules to P256 signatures.
- [EIP-8250: price nonce_keys and nonce_seq as transaction data](https://github.com/ethereum/EIPs/pull/11958), submitted the day before, was merged.

**Why it matters**
- For wallets and gas estimation: users actually pay `charged_gas`, and the order of refund and calldata floor affects the final fee. With the companion EIPs written as deltas, 8250 (keyed nonces) and 8272 (recent root references) can compose independently without overwriting each other.
