## Key topics

### 1. Transaction and account EIPs in Hegotá
**What happened**
- [EIP-8081: PFI EIPs 8131, 8146 and 8250 for Hegotá](https://github.com/ethereum/EIPs/pull/11615) (nerolation), merged. EIP-8250 is keyed nonces and EIP-8146 is BAL sidecars.
- [EIP-8131: rewritten as a Unified Transaction Content Floor](https://github.com/ethereum/EIPs/pull/11738) (nerolation), merged, in preparation for Hegotá: it adds blob versioned hashes, generalizes the idea as user-controlled bytes and updates the impact analysis.
- [EIP-8141: restore the accidentally deleted Behavior section](https://github.com/ethereum/EIPs/pull/11810) (nerolation), submitted.

**Why it matters**
- For privacy and AA: keyed nonces give one account several independent nonce sequences, so privacy pool withdrawals and parallel session key transactions do not have to queue on one nonce. EIP-8131 counts user-controlled bytes such as auth data toward the calldata floor, which affects the cost of AA transactions carrying many signatures.

### 2. EIP-8130 gas accounting fixes
**What happened**
- [EIP-8130: charge initial actor slot writes on account creation](https://github.com/ethereum/EIPs/pull/11812) (chunter-cb), submitted and merged. A create entry's `initial_actors` are written to storage (one `actor_config` slot per actor), but `account_changes_cost` only counted config change and delegation entries, and a create entry was charged for bytecode alone, so registering N actors through a create entry got the slot writes for free.
- [EIP-8130: clarify the intrinsic gas schedule is a recommendation](https://github.com/ethereum/EIPs/pull/11813), submitted: `AA_BASE_COST`, the `nonce_key_cost` table, calldata costs, slot write costs and so on reflect current EIP-2929/EIP-2028 costs and are not fixed protocol constants.

**Why it matters**
- For 8130 account deployment: uncharged storage writes would be a channel for cheap state writes. With the fix, creating an account with several initial keys costs more, and wallets need to estimate gas by the number of actors.
