## Key topics

### 1. Transactions and gas: BALs and state cost
**What happened**
- [Add EIP: Ancestor-Indexed BALs](https://github.com/ethereum/EIPs/pull/11595) (nerolation), submitted: EIP-8247 lets BALs reference ancestor blocks so addresses and storage keys are not listed again.
- [ethresear.ch: Economic State Management via Fixed Storage Bonds and Dynamic Refunds](https://ethresear.ch/t/eip-xxxx-economic-state-management-via-fixed-storage-bonds-and-dynamic-refunds/24781), 16:59: creating new state locks a fixed ETH bond, with forgone staking yield acting as implicit rent; deleting state earns a dynamic protocol funded refund that works as a "state thermostat".

**Why it matters**
- For users: smaller BALs make blocks cheaper to propagate and verify, which helps raise the gas limit; the bond idea tackles the same problem as EIP-8037 state gas, but moves the cost from gas to locked capital.
