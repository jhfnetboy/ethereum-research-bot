## Key topics

### 1. Moving the keyed nonce and recent root specs forward
**What happened**
- [EIP-8250: highlight privacy benefit upfront](https://github.com/ethereum/EIPs/pull/12126) and [EIP-8272: highlight privacy benefit upfront](https://github.com/ethereum/EIPs/pull/12125) (nerolation), merged, briefly stating the motivation for each.
- [EIP-8272: specify RECENT_ROOT_CODE](https://github.com/ethereum/EIPs/pull/12131) (AnkushinDaniil), submitted. Per the PR, `RECENT_ROOT_CODE` is currently TBD, so the recent root contract has fully specified behavior and no code implementing it; a client installing the predeploy today installs an empty account, every write is a plain value transfer that commits nothing, and every later reference fails its check. The PR assembles the code directly from the spec and fills in the constant.

**Why it matters**
- A private transaction has to prove that it references a recent state root, and the recent root contract is that anchor. Without code, devnets cannot test it, so this is a necessary step from spec to implementation.

### 2. Payments and infrastructure privacy
**What happened**
- [ethresear.ch: atomic ZK-proof-gated settlement for x402 agent payments](https://ethresear.ch/t/atomic-zk-proof-gated-settlement-for-x402-agent-payments-a-measured-reference-design/25660), 01:47. The author notes that x402 lets an agent pay for a resource call but never binds payment to correct execution; the ZkInferenceEscrow reference design settles payment for an AI inference call in one transaction, only when an onchain zero-knowledge proof verifies the call ran on a specific pinned circuit.
- [AndyGuzman: infrastructure providers such as RPCs, indexers and bundlers need privacy to avoid regulatory risk](https://x.com/AndyGuzmanEth/status/2085776716404871391), 00:14; anything that can log becomes a pressure point.

**Why it matters**
- Bundlers and RPCs sit on the path of every account abstraction transaction. If they can see and log user data, they can be asked to censor; not logging is itself a censorship resistance measure.
