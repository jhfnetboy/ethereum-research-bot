## Key topics

### 1. ACDC #191: post-quantum moves to the top, Hegotá scope still open
**What happened**
- [ACDC #191 meeting notes](https://ethereum-magicians.org/t/all-core-devs-consensus-acdc-191-november-12-2026/30139) were posted 2026-11-13 00:04 (the call ran 2026-11-12 21:00, with Ben Edgington chairing for the first time). The notes say the call debated raising the urgency of post-quantum and post-AI hardening from DEFCON 4 to DEFCON 2 or 3, because AI math capabilities are moving faster than expected. Including FOCIL and quick slots in Hegotá was contested. Post-quantum Gasper was seen as complex and needs to be weighed against post-quantum decoupled consensus (PQDC). EIP-8483, post-quantum material registration, was accepted as PFI for Hegotá. The next ACDC is set for November 26.
- Follow-ups from the same notes: CL teams will assess PQ Gasper against PQDC for the validator set, time to finality, bandwidth and compute. CL and EL teams will look at how FOCIL interacts with post-quantum work. Tom aims to have leanVM ready for client testing within a few months and production-ready in January. Justin Drake will publish the EF's findings on current cryptographic threats within a few weeks to a month. (Same source, 2026-11-13)
- The notes also cover Toni's DevNet 8 tests with malicious payloads that look valid to CLs but are invalid to ELs because of BAL hash mismatches, which eats a lot of resources. A decision on adding an execution block hash check to gossip validation was postponed, and jtraglia will run a breakout on it. Audit reports on the repricing EIPs 8037 and 8038 will be discussed on Monday's ACDT (11-16). (Same source, 2026-11-13)
- [On the EIP-8483 PR, editor jochem-brouwer suggested merging a draft version first](https://github.com/ethereum/EIPs/pull/12609) in a comment at 2026-11-12 22:44. The EIP adds an EIP-7685 request type and a predeploy so a validator's withdrawal address can register 32 bytes of post-quantum material per validator in the beacon state, for use by a future post-quantum migration fork.
- [Draft EIP: run leanVM aggregation in shadow mode alongside BLS](https://ethereum-magicians.org/t/eip-draft-run-leanvm-aggregation-in-shadow-mode-alongside-bls-until-pq-ai-day/30367), posted 2026-11-12 22:38 by sauliusgrigaitis. Validators would produce both a BLS signature and a post-quantum hash-based signature, consensus would rely on BLS alone, and leanVM aggregates and proofs would only be measured and compared. Once BLS is no longer safe, an emergency hard fork would switch over to leanVM. This matches the staged rollout write-up assigned to saulius in the notes.

**Why it matters**
- This is the first time core devs have treated post-quantum as something that should reshape the schedule in a formal call. PFI for EIP-8483 means pre-registering post-quantum keys is likely headed into Hegotá, which validators and staking providers will need to prepare for.
- For accounts: if Hegotá tilts toward post-quantum, Frames (EIP-8141) becomes even more secure as the foundation for post-quantum accounts. Whether FOCIL survives, though, directly affects censorship resistance for Frame transactions (see EIP-8500 in the next section).
- The DevNet 8 payload issue shows that BAL (block-level access lists) opens a new attack surface, which could affect the Glamsterdam timeline.

**What to watch**
- ACDT #103 on 11-16: the EIP-8037 and EIP-8038 audit results and a fuller report on the DevNet 8 payloads.
- The EF cryptographic threat findings Justin Drake committed to publishing.
- Whether the next ACDC on 11-26 settles FOCIL and quick slots.

### 2. Account abstraction and transactions: EIP-8430 reprices sponsorship, EIP-8500 connects to FOCIL
**What happened**
- [A new commit on the EIP-8430 (AA Transaction Type) PR makes sponsored transactions pay for the sender's account access](https://github.com/ethereum/EIPs/pull/12385), pushed 2026-11-13 04:58. EIP-8430 is a standalone EIP-2718 transaction type split out of EIP-8130 with no Keystore dependency. Today's EOAs can use it with native secp256k1: phased call batching, gas sponsorship (bound and open payer modes), 2D nonces and a nonce-free mode, and in-band EIP-7702-style code delegation.
- [New draft EIP-8500: FOCIL omission witnesses for Frame transactions](https://github.com/ethereum/EIPs/pull/12663), opened 2026-11-13 07:53 by AnkushinDaniil and built on EIP-7805 (FOCIL) and EIP-8369. The payload envelope carries the signed inclusion lists an omission relies on, and the bid commits to their root. An omitted Frame transaction is judged at a check point derived from the BAL. Per-transaction and per-list gas caps are mandatory, with values still to be measured.
- [The EIP-8288 PR enabling batched leanSTARK claims](https://github.com/ethereum/EIPs/pull/12654) got 19 revisions between 2026-11-12 16:57 and 2026-11-13 05:52. One batch leaf can establish independent claims for multiple transactions, regrouping needs no new signature, applications can fund proving for future post-quantum passkeys, and the claim cap per leaf will be set by benchmarks.
- [The draft EIP PR for eth/73 proof wrapper propagation was closed](https://github.com/ethereum/EIPs/pull/12655) at 2026-11-12 23:49 without merging. It would have added a mode to EIP-8437 for submitting raw signatures directly to aggregators.

**Why it matters**
- EIP-8430 is the "native AA that today's EOAs can use" track, running in parallel with EIP-8141 Frames. Charging sponsored transactions for the sender's account access closes a gap where sponsorship could push state access costs onto someone else, and it will change gas estimation for wallets and paymasters.
- EIP-8500 answers whether FOCIL and Frame transactions can coexist. Smart account validation depends on onchain state, which makes it harder for an inclusion list to tell whether a transaction was deliberately left out. If Hegotá keeps FOCIL, this draft is a key companion for censorship-resistant Frames.
- Batched claims in EIP-8288 determine how cheap a post-quantum signature can get per transaction, which is the economic precondition for usable post-quantum accounts.

**What to watch**
- Frame Transaction Breakout #8 on 11/17 ([pm #2295](https://github.com/ethereum/pm/issues/2295)).
- Measured gas caps for EIP-8500, and where the exemption list approach in consensus-specs#5772 ends up.
