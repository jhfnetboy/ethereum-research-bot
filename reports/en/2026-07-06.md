## Key topics

### 1. Protocol groundwork for private transactions
**What happened**
- [soispoke: keyed nonces (EIP-8250) and recent roots (EIP-8272) are now officially proposed for Hegotá](https://x.com/soispoke/status/2074048120082550890), 15:29, with a video and slides on getting to trustless, censorship-resistant privacy protocol transactions.
- [ethresear.ch: Native UTXOs on Ethereum](https://ethresear.ch/t/native-utxos-on-ethereum/25368), 13:52 (Nero_eth). On Ethereum, the first ETH an address receives creates a permanent account leaf, and the first ERC-20 it holds a permanent storage slot; a Bitcoin payment is a one-shot object, created once, spent once and then deleted from state. The post explores borrowing that property.
- [EIP-8141: allow arbitrary signature data to avoid a circular dependency for custom verifiers](https://github.com/ethereum/EIPs/pull/11837) (lightclient), merged, so custom verifiers can use the canonical signing hash.

**Why it matters**
- For privacy and wallets: keyed nonces free transactions such as privacy pool withdrawals from a single sequential nonce, and recent roots let a transaction reference a recent state root; together with frame transactions they can reduce reliance on relayers. If UTXO-style payments land, receiving funds would stop growing state forever, which helps both private payments and state growth.

### 2. Consensus: an extremely lean chain and validator privacy
**What happened**
- [Vitalik: a path to make the Lean consensus chain aggressively leaner and add strong validator privacy](https://x.com/VitalikButerin/status/2074033310875975719), 14:30: ZK-unlinking deposits from staking activity from withdrawals, and re-anonymizing stakers every day.
- [ethresear.ch: The Extremely Lean Chain](https://ethresear.ch/t/the-extremely-lean-chain/25369), 14:00 (vbuterin). With Lean upgrades such as single-slot finality and recursive-STARK-based quantum-resistant signature aggregation, stakers take responsibility for managing and occasionally ZK-proving their state, removing end-of-epoch processing (which in few-slot finality may run every 16 seconds) and possibly letting consensus scale to millions of validators.
- [New EIP: Hash-Chain RANDAO](https://github.com/ethereum/EIPs/pull/11861) (kevaundray), submitted, with a [Magicians thread](https://ethereum-magicians.org/t/eip-8321-hash-chain-randao/28942) at 05:50; this is EIP-8321.
