## Key topics

### 1. Accounts: native AA and post-quantum migration
**What happened**
- [gakonst: migrating Tempo users to post-quantum signatures will be easier than elsewhere because of native AA: add a new key to the existing account without transferring or migrating assets, then disable non post-quantum keys (opt in or via a protocol upgrade)](https://x.com/gakonst/status/2047750718191452581), 01:53.
- [gakonst: experimenting with post-quantum signature aggregation on openvm](https://x.com/gakonst/status/2047774398162276544), 03:27.

**Why it matters**
- For accounts: in the EOA model the address is the key, so changing keys means changing addresses and moving assets; once accounts and keys are decoupled, post-quantum migration becomes a key rotation, one of the main reasons Ethereum is pushing native AA.

### 2. Transactions and gas: an EIP-8037 revision
**What happened**
- [EIP-8037: proposal for revising 8037](https://github.com/ethereum/EIPs/pull/11570) (Carsons-Eels), submitted: the STEEL team tries to reconcile issues in the current EIP-8037 definition and effects found during implementation and testing, with some details still to be specified.

**Why it matters**
- For users: right after ACDE #235 raised complexity concerns about EIP-8037, the testing team offered a revision, showing state gas design is still being refined at the implementation level.
