## Key topics

### 1. Transaction safety: the Trust Wallet extension incident
**What happened**
- [TrustWallet: about $7M stolen via browser extension v2.68, do not open it, disable and upgrade, users will be refunded](https://x.com/TrustWallet/status/2004475085168795941), 15:51, per [Ethereal news #4](https://ethereal.news/ethereal-news-weekly-4/); [Ethereal news #5](https://ethereal.news/ethereal-news-weekly-5/) later said attackers likely used November's Sha1-Hulud 2 npm supply chain attack to get source code and a web store API key.

**Why it matters**
- For transactions: when the wallet software itself is replaced, nothing users sign can be trusted, and hardware signing plus verified simulation are the backstop.
