## Key topics

### 1. Native AA: EIP-8141 becomes CFI for Hegotá
**What happened**
- [EIP-8081: add EIP-8141 to CFI, EIP-7716 and EIP-8205 to PFI](https://github.com/ethereum/EIPs/pull/11537) (dionysuzx), merged, recording decisions from ACDE #233 and ACDC #177.
- [EIP-8141: relax mempool rules to not require a specific factory](https://github.com/ethereum/EIPs/pull/11567) (derekchiang), merged.
- [EIP-8141: add 2D nonces](https://github.com/ethereum/EIPs/pull/11584) (nerolation), submitted: adds nonce_key so (nonce_key, nonce) selects one of the sender's nonce sequences, increments that sequence on payment approval and charges a nonce_key cost at SSTORE pricing (0, 5000 or 22100).

**Why it matters**
- For accounts: CFI in the meta EIP means client teams implement frame transactions as part of Hegotá scope; 2D nonces let one account send parallel transactions that do not block each other, like ERC-4337 nonce keys, but a new key carries a storage cost.

### 2. Transactions and gas: relaying and pricing
**What happened**
- [Add EIP: Generic Relayer Architecture for Smart Accounts](https://github.com/ethereum/EIPs/pull/11583) (seansing), submitted: defines a relayer_* JSON-RPC namespace for fee discovery, transaction submission (including multichain) and capability queries, supporting gasless and token fee transactions; the PR later moved to the ERCs repo.
- [EIP-2780: add the missing EIP-7708 log cost for CREATE with endowment](https://github.com/ethereum/EIPs/pull/11586) (danceratopz), submitted: a top level CREATE with value > 0 adds TRANSFER_LOG_COST to intrinsic gas.
- [EIP-7709: move to Draft](https://github.com/ethereum/EIPs/pull/11587) (jsign), submitted: revived from Stagnant with stale Verkle language removed.

**Why it matters**
- For users: one relayer interface lets wallets plug into different sponsors without custom integrations; the EIP-2780 fix stops contract creation with value from underpaying the log cost.
