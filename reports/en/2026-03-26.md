## Key topics

### 1. Native AA: EIP-8141 is CFI for Hegotá
**What happened**
- [ACDE #233](https://forkcast.org/calls/acde/233), 21:00, per [Ethereal news #17](https://ethereal.news/ethereal-news-weekly-17/): Hegotá has no execution layer headliner, and [EIP-8141](https://forkcast.org/eips/8141) frame transactions are Considered for Inclusion as a non headliner.
- [EIP-8141: add support for atomic batching](https://github.com/ethereum/EIPs/pull/11395) (derekchiang), merged after submission on March 11; [EIP-8141: add mempool policy](https://github.com/ethereum/EIPs/pull/11415) (lightclient), merged after submission on March 17; [EIP-8141: update default code to match the latest spec](https://github.com/ethereum/EIPs/pull/11448) (derekchiang), submitted and merged.

**Why it matters**
- For accounts: CFI means client teams start implementing and testing it within Hegotá scope; frame transactions make verification logic, gas payment and batching native, and EOA users get them through the default code without relying on ERC-4337 bundlers.
- For gas: the mempool policy replaces the staking reputation system with a canonical paymaster contract so sponsored transactions can travel through the public mempool, and atomic batching lets multi step flows such as approve plus swap finish in one transaction.
