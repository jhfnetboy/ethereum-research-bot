## Key topics

### 1. EIP-8333 checkpoint alignment
**What happened**
- [New EIP: Align Checkpoint with Epoch Boundary Block](https://github.com/ethereum/EIPs/pull/11871) (wemeetagain), merged as a Draft, EIP-8333. Checkpoint epochs stay the same and only the root changes, through a new `get_checkpoint_root` helper used in attestation processing, justification, fork choice and the validator guide. Today the target block is proposed in the same slot the first committee votes, so a late block splits their votes, a measurable loss every epoch; the boundary block is known before the epoch starts, so the race disappears.

**Why it matters**
- For stakers: target votes in the first slot become more stable, reducing reward losses from late blocks.
