## Key topics

### 1. Native AA: EIP-8141 and EIP-8130
**What happened**
- [EIP-8141: fix some issues](https://github.com/ethereum/EIPs/pull/11344) (derekchiang), submitted: removes several statements that APPROVE requires CALLER == frame.target, since in a typical VERIFY frame CALLER is ENTRY_POINT and frame.target is tx.sender.
- [Add ERC: Payer Service Capability](https://github.com/ethereum/ERCs/pull/1555) (chunter-cb), submitted: a payer_* JSON-RPC interface wallets use to negotiate gas sponsorship and token gas payment when building EIP-8130 native AA transactions, extending the existing paymaster capability.
- [Magicians: Operational primitives for AA, lane separation, fixed execution phases and versioned upgrades](https://ethereum-magicians.org/t/operational-primitives-for-aa-lane-separation-fixed-execution-phases-and-versioned-upgrades/27789), 19:32, a design and reference implementation for modular ERC-4337 style smart accounts.

**Why it matters**
- For gas: a standard interface between wallets and sponsors decides whether sponsorship works across wallets, key to users transacting without ETH once native AA ships.
