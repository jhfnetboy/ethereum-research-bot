## Key topics

### 1. Native AA: converging on EIP-8141
**What happened**
- [EIP-7701: move to Withdrawn](https://github.com/ethereum/EIPs/pull/11472) (forshtat), submitted; 7701 was the earlier EOF based native AA proposal; [Add EIP: Commit-Reveal Transaction Frames](https://github.com/ethereum/EIPs/pull/11466) (forshtat), merged after submission on March 29.
- [EIP-8037: clarify state gas behavior on frame failure (child vs top-level)](https://github.com/ethereum/EIPs/pull/11468) (qu0b), submitted: on child frame failure execution_state_gas_used returns to the parent's reservoir rather than accumulating, and on top level exceptional halt it is not reset and still counts toward block_state_gas_used.

**Why it matters**
- For accounts: with EIP-8141 now CFI, the author withdrawing 7701 and moving to frame transaction extensions means the native AA design contest has largely converged.
- For gas: whether a top level failure refunds state gas sets the real cost of failed transactions, and an alternative PR the next day proposed the opposite.

### 2. Privacy: Aztec Alpha and PIR
**What happened**
- [aztecnetwork: Alpha is live, after nearly a decade the first feature complete privacy stack on Ethereum, with privacy customizable from execution to settlement](https://x.com/aztecnetwork/status/2038970103459709020), 20:22.
- [ethresear.ch: Sharded PIR Design for the Ethereum State](https://ethresear.ch/t/sharded-pir-design-for-the-ethereum-state/24552) (aliatiia and Keewoo Lee), 04:30: private information retrieval lets users read chain data from remote servers without the server learning what was read; PIR schemes trade off differently and Ethereum data varies in update rate and latency sensitivity, so sharding data and pairing each set with its best scheme gives better overall performance at the same privacy.
- [Add ERC: Wallet Signature and Calldata Digest Display](https://github.com/ethereum/ERCs/pull/1639) (PatrickAlphaC), submitted: defines EIP-712 digest, domain hash, message hash and calldata digest, and requires wallets to display them for independent verification.

**Why it matters**
- For privacy: wallets leak addresses and interests when querying RPC for balances and state, and PIR protects read privacy without running a node.
