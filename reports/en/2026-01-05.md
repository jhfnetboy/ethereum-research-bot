## Key topics

### 1. Calls: ACDE #227
**What happened**
- [ACDE #227](https://forkcast.org/calls/acde/227), 21:00 (off cycle), per [Ethereal news #6](https://ethereal.news/ethereal-news-weekly-6/): Glamsterdam targets June 2026; [EIP-7997](https://forkcast.org/eips/7997/), the deterministic factory predeploy, is CFI; the contract size limit choice between EIP-7907 and EIP-7954, EIP-7903 and [EIP-8037](https://forkcast.org/eips/8037/) wait for the next ACDE; EIP-8058 bytecode dedup discount, EIP-7668 removing bloom filters and EIP-7745 trustless log index are declined.

**Why it matters**
- For accounts: a deterministic factory predeploy lets smart accounts deploy at the same address on every chain, base infrastructure for cross chain AA wallets.

### 2. Signatures and transaction formats
**What happened**
- [EIP-6404: update to the new EIP-7932 registry](https://github.com/ethereum/EIPs/pull/10926) (SirSpudlington), merged after submission on December 16, 2025; [EIP-5792: add the missing 6xx category for status code 600](https://github.com/ethereum/EIPs/pull/11025) (PivasDesant), submitted.

**Why it matters**
- For transactions: with SSZ transactions tied to the signature algorithm registry, future post-quantum signed transactions need no new transaction structure.
