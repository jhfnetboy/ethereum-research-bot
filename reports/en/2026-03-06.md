## Key topics

### 1. Native AA: the initial EIP-8130
**What happened**
- [EIP-8130: simplify for the initial EIP](https://github.com/ethereum/EIPs/pull/11380) (chunter-cb), submitted and merged: an AA model that is performant and can run a mempool safely, with mempool storage limited to world state, contract code for trusted verifiers and canonical addresses, and account config contract state; [EIP-8130: slot derivations left to the final contract](https://github.com/ethereum/EIPs/pull/11378) (chunter-cb), merged.

**Why it matters**
- For accounts: limiting validation to a small set of known state lets the mempool check smart account transactions as cheaply as EOA ones, 8130's main selling point against 8141.

### 2. Gas and transactions
**What happened**
- [EIP-8037: clarify reservoir mechanics](https://github.com/ethereum/EIPs/pull/11328) (spencer-tb), merged after submission on February 17.
- [Magicians: ERC-8176, Integrity Verification for ERC-7730](https://ethereum-magicians.org/t/erc-8176-integrity-verification-for-erc-7730/27911), 15:01.

**Why it matters**
- For transactions: ERC-7730 lets wallets render calldata as readable text, and a tampered descriptor would mislead signers, which integrity verification guards against.
