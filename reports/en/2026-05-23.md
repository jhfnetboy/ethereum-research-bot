## Key topics

### 1. Accounts and transactions
**What happened**
- [New EIP: Expiring Nonces for Frame Transactions](https://github.com/ethereum/EIPs/pull/11692) (nerolation), merged as EIP-8266.
- [New EIP: Gas Limit Schedule](https://github.com/ethereum/EIPs/pull/11644) (barnabasbusa), merged as EIP-8261.
- [EIP-7928: add GAS_COPY to EXTCODECOPY](https://github.com/ethereum/EIPs/pull/11718), merged; [EIP-8038: add state_access_gas_reservoir](https://github.com/ethereum/EIPs/pull/11725), submitted.

**Why it matters**
- For accounts: with keyed nonces and expiring nonces both in the repo, the frame transaction nonce model moves from a single increasing queue to a structure that can run in parallel and expire, a foundation privacy protocols and multi-device wallets need.

### 2. State and consensus
**What happened**
- [New EIP: Storage Roots in Block Access Lists](https://github.com/ethereum/EIPs/pull/11716) (CPerezz), merged as EIP-8268.
- [New EIP: Cap Deposit Requests Per Block](https://github.com/ethereum/EIPs/pull/11607) (barnabasbusa), merged, with `MAX_DEPOSIT_REQUESTS_PER_BLOCK = 8192` matching the consensus layer SSZ bound; an 8193rd request breaks CL decoding, observed empirically at about 193M gas.
- EIP-8081 Hegotá meta EIP: [add EIP-8188](https://github.com/ethereum/EIPs/pull/11722) and [add EIP-4758](https://github.com/ethereum/EIPs/pull/11724), merged.

### 3. Networking
**What happened**
- [ethresear.ch: AetherWeave, stake-backed peer discovery for Ethereum](https://ethresear.ch/t/aetherweave-stake-backed-peer-discovery-for-ethereum/24927), 01:12 (Kaya Alpturer, Constantine Doumanidis, Aviv Zohar): the consensus layer makes identities expensive, but peer discovery still treats network identities as cheap, leaving nodes exposed to eclipse and Sybil attacks before consensus even begins.
