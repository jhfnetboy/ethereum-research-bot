## Key topics

### 1. Native AA: EIP-8141 supports EOAs
**What happened**
- [EIP-8141: add EOA support](https://github.com/ethereum/EIPs/pull/11379) (derekchiang), submitted: if a frame is in VERIFY mode and frame.target has no code, frame.data is read as (scope, v, r, s) and checked as a valid signature.
- [EIP-8141 Frame Transaction headliner breakout #1](https://forkcast.org/calls/one-off-1954/001/) met; agenda on [Magicians](https://ethereum-magicians.org/t/headliner-breakout-eip-8141-frame-transaction-march-5-2026/27879).

**Why it matters**
- For accounts: EOAs get batching, gas sponsorship and other frame transaction features without first migrating to a smart account, a key change in EIP-8141's bid to headline Hegotá.

### 2. Agent payments and accounts
**What happened**
- [Add ERC: Agentic Commerce](https://github.com/ethereum/ERCs/pull/1581) (dcrapis), submitted; [Magicians thread ERC-8183](https://ethereum-magicians.org/t/erc-8183-agentic-commerce/27902), 04:49: job based escrow where a client funds a job, a provider submits work and a single evaluator attests completion or rejection, with optional hooks composing with ERC-8004 reputation and ERC-2771 gasless flows.
- [EIP-8130: verifier gas and cross chain signatures update](https://github.com/ethereum/EIPs/pull/11374) (chunter-cb), merged; [EIP-8130: slot derivations left to the final contract](https://github.com/ethereum/EIPs/pull/11378) (chunter-cb), submitted; [ERC-8186: Identity Account](https://ethereum-magicians.org/t/erc-8186-identity-account/27905), 16:15.
