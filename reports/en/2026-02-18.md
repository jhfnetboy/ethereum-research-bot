## Key topics

### 1. Roadmap: EF Protocol priorities for 2026
**What happened**
- [EF blog: Protocol Priorities Update for 2026](https://blog.ethereum.org/en/2026/02/18/protocol-priorities-update-2026) (Protocol track leads): in 2025 Pectra shipped EIP-7702, letting EOAs run contract code for batching, gas sponsorship and social recovery, and doubled blob throughput; 2026 has three tracks, Scale (Ansgar, Marius, Raúl), Improve UX (Barnabé, Matt) and Harden the L1 (Fredrik, Pari, Thomas).

**Why it matters**
- For accounts: with Improve UX as its own track, native AA and follow up work on EIP-7702 get named owners and resources.

### 2. Accounts: native key delegation for EOAs
**What happened**
- [Add EIP: Native Key Delegation for EOAs](https://github.com/ethereum/EIPs/pull/11330) (prestwich), submitted: extends EIP-7702 delegation to non ECDSA keys with a new transaction type for native key delegation and signing, starting with ed25519.
- [EIP-2780: clarify interactions with other EIPs](https://github.com/ethereum/EIPs/pull/11332) (gurukamath), submitted.

**Why it matters**
- For accounts: swappable signature schemes are the precondition for post-quantum migration, and a general key delegation framework for EOAs means a PQ key later is just a new type.

### 3. Privacy: agent payments
**What happened**
- [ethresear.ch: PrivateX402, privacy preserving payment channels for multi agent AI systems](https://ethresear.ch/t/privatex402-privacy-preserving-payment-channels-for-multi-agent-ai-systems/24151) (Conor McMenamin and Artem Grigor of Nethermind), 16:04: current protocols reveal which agents a user pays and how much, leaking intent and behavior, while a centralized facilitator can hide this but adds a single point of failure.
