## Key topics

### 1. Privacy: access layer metadata
**What happened**
- [raulvk: privacy should be the universal default, not a cypherpunk flag; every onchain read and write leaks metadata to the ISP, DNS, RPC, indexer, bundler and chain; Hermetic is a modular playground for access layer privacy, still very alpha](https://x.com/raulvk/status/2052809187759931556), 00:53.

**Why it matters**
- For privacy: even when a transaction is hidden with ZK, a wallet checking balances or sending an ERC-4337 UserOperation through a bundler links IPs to addresses, so privacy has to cover the whole path from network to chain.
