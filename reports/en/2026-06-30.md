## Key topics

### 1. Protocol foundations for privacy dapps
**What happened**
- [soispoke: on Thursday's ACDE I'll propose Keyed Nonces (EIP-8250) and Recent Roots (EIP-8272) for Hegota](https://x.com/soispoke/status/2071923344165716344), 18:46; these two EIPs sit on top of frame transactions and are important primitives for making privacy dapp transactions censorship resistant and trustless.
- [ethbeat: presenting L2BEAT's new privacy dashboard at Brew Berlin](https://x.com/ethbeat_org/status/2071950806702571972), 20:35; at the center of every privacy pool tracked is the anonymity set, the crowd your transaction hides in.
- [aztecnetwork: the Alpha V5 code is ready, with significant security updates, speed improvements and new features to simplify privacy UX](https://x.com/aztecnetwork/status/2071657649725440005), 01:10. [Aztec: the bug bounty on Cantina is still open](https://x.com/aztecnetwork/status/2071730436338761760), 06:00.

**Why it matters**
- For privacy dapps: privacy pool withdrawals today often rely on relayers to pay gas and submit transactions, and relayers can censor. Frame transactions let a withdrawal validate itself with gas paid by a contract, keyed nonces keep multiple withdrawals from contending for one nonce, and recent roots bind the transaction to a recent state root. Anonymity set size then decides how much privacy these transactions actually provide.

### 2. Post-quantum migration
**What happened**

[Eli Ben-Sasson: much of Starknet's underlying cryptography is already post-quantum secure, so the migration path is relatively short](https://x.com/EliBenSasson/status/2071946484220621232), 20:18.
- [trailofbits: 1.2 billion downloads ran through pyca/cryptography last month, and if it doesn't ship post-quantum primitives the Python ecosystem can't migrate](https://x.com/trailofbits/status/2071915420584411634), 18:15.

**Why it matters**
- For wallets and infrastructure: post-quantum migration is not only about onchain signature schemes; the general cryptography libraries that wallets, nodes and backends depend on must support the new primitives first.
