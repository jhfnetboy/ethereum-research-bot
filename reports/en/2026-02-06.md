## Key topics

### 1. Native AA and authorization pricing
**What happened**
- [EIP-8141: disable the EIP-3607 check for frame transactions](https://github.com/ethereum/EIPs/pull/11272) (Thegaram), submitted, with discussion in the [EIP-8141 Magicians thread](https://ethereum-magicians.org/t/eip-8141-frame-transaction/27617/26).
- [Add EIP: Add Auth Data to EIP-7623 Floor](https://github.com/ethereum/EIPs/pull/11148) (nerolation), merged after submission on January 22.

**Why it matters**
- For accounts and gas: EIP-3607 forbids senders with code, so frame transactions keeping the check would lock out delegated or deployed accounts; counting authorization data in the floor closes a loophole for stuffing cheap data into EIP-7702 authorization lists.

### 2. Transactions: agent payments
**What happened**
- [Add ERC: Zero-Knowledge Agent Payment Verification](https://github.com/ethereum/ERCs/pull/1519) (jqhc), submitted, with the [ERC-8150 thread](https://ethereum-magicians.org/t/erc-8150-zero-knowledge-agent-payment-verification/27665), 13:51: inspired by ERC-8004, users sign off on an agent's batch, and the agent must submit a ZK proof that its transactions match the signed intent before any funds move.
