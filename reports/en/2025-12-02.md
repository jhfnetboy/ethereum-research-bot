## Key topics

### 1. Transaction privacy: threshold encrypted mempools
**What happened**
- [ethresear.ch: Threshold encrypted mempools with mev-commit preconfirmations](https://ethresear.ch/t/threshold-encrypted-mempools-with-mev-commit-preconfirmations/23588) (pepae), 21:12: by Primev and Shutter Network authors; users lose value daily to frontrunning, so transactions stay encrypted until threshold decryption, with preconfirmations promising inclusion.

**Why it matters**
- For privacy: before an enshrined encrypted mempool lands, threshold encryption plus preconfirmations is transaction privacy that can ship now.

### 2. Transactions: the FOCIL debate
**What happened**
- [nero_eth: censorship resistance is not binary and FOCIL does not materially improve it, speeding up very few transactions while most get broadcast twice](https://x.com/nero_eth/status/1995861708968264132), 21:24; [soispoke: FOCIL was never meant for short term impact, which would only show if massive censorship had already happened](https://x.com/soispoke/status/1995787032476443037), 16:28.
