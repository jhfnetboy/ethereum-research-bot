## Key topics

### 1. Privacy and gas: counterfactual transactions
**What happened**
- [New EIP: Counterfactual Transaction (EIP-8224)](https://github.com/ethereum/EIPs/pull/11518) (benaadams), submitted: a new EIP-2718 transaction type `0x08` for protocol native shielded gas funding using ZK proofs against canonical fee note contracts; [Magicians discussion](https://ethereum-magicians.org/t/eip-8224-counterfactual-transaction/28205), 08:33.

**Why it matters**
- For privacy: a fresh address with no ETH cannot pay gas, and receiving ETH from anywhere leaves an onchain link that breaks the anonymity of things like privacy pool withdrawals; building private gas payment into the protocol closes the most common last step leak in privacy systems.

### 2. Accounts: native keys and ECRECOVER
**What happened**
- [New EIP: ECRECOVER native key awareness](https://github.com/ethereum/EIPs/pull/11515) (prestwich), submitted: a companion to EIP-8164 (native key delegation for EOAs) that changes the ECRECOVER precompile at `0x01`; if the recovered address has a native key delegation (`0xef01` plus a nonzero byte) it returns empty, so contracts stop accepting signatures from the retired ECDSA key.

**Why it matters**
- For accounts: if an EOA moves to a new key but the old private key can still sign in ecrecover based contracts such as permit, the migration is incomplete; this guard makes key rotation, including moving to post-quantum keys, actually take effect.
