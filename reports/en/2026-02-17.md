## Key topics

### 1. Transaction privacy: EIP-8105
**What happened**
- [Add EIP: Universal Enshrined Encrypted Mempool](https://github.com/ethereum/EIPs/pull/10943) (jannikluhn), merged; it is EIP-8105, a Hegotá headliner candidate.

**Why it matters**
- For transactions: an enshrined encrypted mempool keeps transactions hidden until ordering is fixed, removing frontrunning and sandwiching at the protocol layer instead of relying on private relays.

### 2. Gas and execution
**What happened**
- [EIP-8037: clarify reservoir mechanics](https://github.com/ethereum/EIPs/pull/11328) (spencer-tb), submitted: fixes small issues found while implementing in EELS, documents how the calldata floor interacts with refunds, and clarifies that refund_counter is a single undimensioned counter with EIP-7702 authorization refunds going to state gas.
- [Add EIP: Reserve EXTENSION (0xae) opcode](https://github.com/ethereum/EIPs/pull/11327) (pdobacz), submitted, with the [Magicians thread EIP-8163](https://ethereum-magicians.org/t/eip-8163-reserve-extension-0xae-opcode/27756), 19:22; [Add EIP: Block Access List Sidecars](https://github.com/ethereum/EIPs/pull/11254) (nerolation), merged; [EIP-7976: update empirical report](https://github.com/ethereum/EIPs/pull/11326) (nerolation), submitted and merged.

**Why it matters**
- For gas: EIP-7702 authorizations create account state, so refunding them into state gas keeps the accounting consistent with state pricing.
