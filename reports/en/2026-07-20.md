## Key topics

### 1. Kohaku CLI and account-layer privacy
**What happened**
- [kassandraETH: a way for Ethereum users to try Kohaku, as a live demo on mainnet](https://x.com/kassandraETH/status/2079238186018931113), 23:13. Per Ethereal news #32, kohaku-cli is a terminal wallet that can unshield and swap in a single ERC-4337 operation funded from Tornado Cash; it is a work in progress and not security reviewed.
- [kassandraETH: from a privacy view, the CLI talks over HTTP to only two servers, the Ethereum RPC endpoint and Pimlico's public endpoint for submitting 4337 UserOps](https://x.com/kassandraETH/status/2079245166649516376), 23:40.
- [binji: breakthroughs are happening in Ethereum privacy, introducing programmable privacy while keeping full user sovereignty](https://x.com/binji_x/status/2079155774245240961), 17:45.

**Why it matters**
- For wallets: withdrawing from a privacy pool usually needs a fresh address with gas; doing the unshield and swap inside one 4337 UserOp helps reduce links such as "fund the new address with gas first". The RPC and bundler still see the requests, which is a privacy boundary users should know.

### 2. Hegotá and the frame transaction family
**What happened**
- [EIP-8081: propose EIP-8272 for Hegotá](https://github.com/ethereum/EIPs/pull/11831) (soispoke), merged, listing it as PFI. [EIP-8272: resolve the RECENTROOTREFLOAD opcode collision](https://github.com/ethereum/EIPs/pull/11967), merged.
- soispoke also submitted [EIP-8250: clarify NONCE_MANAGER activation](https://github.com/ethereum/EIPs/pull/11972), requiring its address to differ from 8141's `EXPIRY_VERIFIER` and making the activation block invalid if code or storage appears there before activation, and [EIP-8272: clarify signature hashing and predeploy address](https://github.com/ethereum/EIPs/pull/11973).
- ACDT #88 was held in the evening; per Ethereal news #32, glamsterdam-devnet-7 is in chaos testing and stable containers need optimization, being about 10% to 20% slower.

**Why it matters**
- For the AA roadmap: 8141 is CFI for Hegotá, and 8250 and 8272 are entering candidacy as companion extensions, deciding whether frame transactions ship with keyed nonces and recent root references.
