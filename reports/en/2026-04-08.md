## Key topics

### 1. Accounts: native key delegation for EOAs
**What happened**
- [Add EIP: Native Key Delegation for EOAs](https://github.com/ethereum/EIPs/pull/11330) (prestwich), merged after submission on February 18: extends EIP-7702 delegation to non ECDSA key types, adds a transaction type supporting both native key delegation and native key signing, with ed25519 as the first non ECDSA type.
- [Magicians: Extensible Execution Transaction for Account Capabilities](https://ethereum-magicians.org/t/extensible-execution-transaction-for-account-capabilities/28168), 15:32; [ethereum: ERC-8211 lets users and agents express multi step composable actions as a simple off chain script with built in safety](https://x.com/ethereum/status/2041573357695459379), 00:46.

**Why it matters**
- For accounts: EOAs using keys like ed25519 can work directly with device secure elements and other ecosystems' signers, and the delegation framework can later carry post-quantum keys.

### 2. Gas: EIP-2780
**What happened**
- [EIP-2780: add a transfer log cost, remove PAY](https://github.com/ethereum/EIPs/pull/11493) (benaadams), submitted and merged: removes the PAY opcode rejected for this fork; since the reduced base cost no longer absorbs EIP-7708's LOG3 transfer event, adds TRANSFER_LOG_COST = 1,756 and updates derived gas totals and capacity tables.

**Why it matters**
- For gas: EIP-2780 lowers base gas for plain transfers, and every ETH transfer now emits a log, so pricing the log separately keeps the reduced figure honest.
