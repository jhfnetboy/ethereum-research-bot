## Key topics

### 1. Name resolution for stealth addresses
**What happened**
- [Magicians: draft proposal for Stealth Name Resolution, stealth meta-address names across asynchronous chains](https://ethereum-magicians.org/t/draft-proposal-stealth-name-resolution-stealth-meta-address-names-across-asynchronous-chains/28787), 03:54 (collinsadi). A canonical Ethereum registry acts as both registrar and ENSIP-10 wildcard resolver for a parent ENS name, serving a `com.opaque.meta` text record; it can store keys directly or source them live from the ERC-6538 registry. The draft also defines a transport-agnostic mirror payload so a second chain can keep read-only name records without querying an Ethereum RPC.

**Why it matters**
- For private payments: one hard part of stealth addresses is how a recipient publishes a meta-address and how a payer finds it. Tied to ENS names, wallets can resolve stealth meta-addresses like ordinary addresses and generate a fresh address for each payment.
