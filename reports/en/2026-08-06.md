## Highlights

2. **7702 delegation**: delegation indicators become account header leaves, so clearing a delegation no longer requires asking whether any other account still delegates to the same target.

## Key topics

### 1. Gas details for accounts and transactions
**What happened**
- [EIP-8141: pin the initial accessed_addresses set for frame transactions](https://github.com/ethereum/EIPs/pull/12113) (Marchhill), submitted. The spec did not define the initial warm set for frame transaction processing, so `gas_used` could diverge at the first `tx.sender` access (some clients charge it COLD, while EIP-2929/3651 warm it); the PR pins the set to the EIP-2929/EIP-3651 set (`tx.sender`, coinbase, precompiles) minus any frame target.
- [EIP-8297: store delegation indicators in the account header](https://github.com/ethereum/EIPs/pull/12114) (CPerezz), merged, with the companion [EIP-8347 PR](https://github.com/ethereum/EIPs/pull/12115) merged the same day. Previously EIP-7702 delegation indicators were content-addressed code chunks in `CODE_ZONE`, so every account delegating to the same target shared one leaf; clearing or replacing a delegation forced a client to determine whether any account anywhere still delegated to that target, which cannot be answered block-locally.
- [Magicians: EIP-8358 net gas metering for account changes](https://ethereum-magicians.org/t/eip-8358-net-gas-metering-for-account-changes/29304), 04:40 (rakita). Mirroring the EIP-2200 scheme for storage, an account counts as changed only once its balance or nonce differs from its value at the start of the transaction, and the value transfer cost of CALL and CALLCODE follows from that.
- [Magicians: draft for preferential gas costs on native ETH operations](https://ethereum-magicians.org/t/eip-0000-preferential-gas-costs-for-native-eth-operations-draft-for-feedback/29302), 02:37; its 0.75 factor still needs client benchmarking against concurrent changes such as EIP-8038.

**Why it matters**
- Gas for native AA and 7702 accounts has to match across all clients or the chain splits. With delegation indicators in the account header, the cost of revoking a delegation under the binary tree state can be determined locally.
