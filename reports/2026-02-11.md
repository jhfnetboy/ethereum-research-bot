## 重点话题

### 1. 隐私：ZK API 使用额度
**发生了什么**
- [ethresear.ch：ZK API 使用额度，LLM 及更多](https://ethresear.ch/t/zk-api-usage-credits-llms-and-beyond/24104)（dcrapis 与 VitalikButerin）20:34：API 计量难以同时兼顾隐私、安全与效率；Web2 认证把每次请求与真实身份挂钩，每次请求都上链付费又慢又贵且难以隐藏交易图谱，方案用零知识证明的预付额度解决。

**为什么重要**
- 对隐私：用户向 LLM 提交的往往是最敏感的个人数据，付费方式决定能否把请求与身份分开，这是以太坊隐私工具在 AI 场景的直接落点。
