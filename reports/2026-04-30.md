## 重点话题

### 1. 原生 AA：EIP-8141 进入 Hegotá CFI
**发生了什么**
- [EIP-8081：把 EIP-8141 列为 CFI，EIP-7716 与 EIP-8205 列为 PFI](https://github.com/ethereum/EIPs/pull/11537)（dionysuzx）合并，决定分别来自 ACDE #233 与 ACDC #177。
- [EIP-8141：放宽内存池规则，不再要求特定工厂](https://github.com/ethereum/EIPs/pull/11567)（derekchiang）合并。
- [EIP-8141：加入二维 nonce](https://github.com/ethereum/EIPs/pull/11584)（nerolation）提交：新增 nonce_key，由 (nonce_key, nonce) 选择发送者的某条 nonce 序列，批准支付时递增对应序列，并按 SSTORE 定价收取 nonce_key 成本（0、5000 或 22100）。

**为什么重要**
- 对账户：CFI 写入 meta EIP 意味着客户端团队要按 Hegotá 范围实现 frame 交易；二维 nonce 让同一账户能并行发出互不阻塞的交易，类似 ERC-4337 的 nonce key，但使用新 key 有存储成本。

### 2. 交易与 gas：中继与计费
**发生了什么**
- [新增 EIP：智能账户通用中继架构](https://github.com/ethereum/EIPs/pull/11583)（seansing）提交：定义 relayer_* JSON-RPC 命名空间，覆盖费用发现、交易提交（含多链）与能力查询，支持无 gas 与代币付费交易；该 PR 后改到 ERC 仓库。
- [EIP-2780：补上带转账的 CREATE 缺失的 EIP-7708 日志成本](https://github.com/ethereum/EIPs/pull/11586)（danceratopz）提交：顶层 CREATE 且 value > 0 时，在固有成本中额外加 TRANSFER_LOG_COST。
- [EIP-7709：移至 Draft](https://github.com/ethereum/EIPs/pull/11587)（jsign）提交：从 Stagnant 恢复为 Draft，删除过时的 Verkle 表述。

**为什么重要**
- 对用户：统一的中继接口让钱包可以接入不同的赞助方，而不必为每家写适配；EIP-2780 的修正避免带转账的合约创建少收日志成本。
