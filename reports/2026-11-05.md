## 重点话题

### 1. Lean Ethereum 分叉路线与 lean transactions
**发生了什么**
- [EF：Lean Ethereum 的逐个分叉计划](https://x.com/ethereumfndn/status/2118150051574747523) 08:15 发布。strawmap 定的目标是 2029 年完成 Lean Ethereum；H* 是最后一个没有 lean 特性的分叉，I* 上线 leanVM 和 lean transactions，J* 加入 lean attestations、DA 采样和 PCS，到 L* 全部完成。
- [Thomas Coratger：Mission 2028 以形式化验证为核心，EthLib 在推进](https://x.com/tcoratger/status/2118264044930932851) 15:47。

**为什么重要**
- lean transactions 意味着账户签名和交易格式会换代，和 EIP-8141 frame transaction 以及 PQ 签名聚合（EIP-8288）是同一条线。对钱包和合约账户开发者，I* 是需要重点准备的分叉。

**接下来关注**
- lean transactions 的具体 EIP；它和 frame transaction 是合并还是并行。

### 2. 账户与签名聚合：EIP-7851、EIP-8288
**发生了什么**
- [EIPs PR #12630：EIP-7851 在归档前同步 EIP-8298 的相关澄清](https://github.com/ethereum/EIPs/pull/12630) 22:26 合并。EIP-7851 是“代码控制的 EOA 委托”，EIP-8298 是 SETCODEFROM 代码复用指令；标题写明是“归档前”的同步。
- [EIPs PR #12628：EIP-8288 只聚合当前可执行的交易](https://github.com/ethereum/EIPs/pull/12628) 15:06 提交。建议聚合者只证明在当前链头可执行的交易，构建者优先选覆盖更多依赖的递归输入。起因是核心开发者担心，内存池里大量低于 base fee 的交易会产生大部分被丢弃的聚合证明。
- [EIPs PR #12599：EIP-8450 处理合并后评审意见](https://github.com/ethereum/EIPs/pull/12599) 14:43 合并（EIP-8450：Post-Quantum Consensus Key Registry，作者 kevaundray）。

**为什么重要**
- 7702 之后，“EOA 怎么升级成合约账户、怎么撤销”有多个竞争提案。EIP-7851 准备归档，说明讨论在向少数方案收敛。EIP-8288 决定 PQ 签名在内存池里怎么被聚合，直接影响未来 PQ 账户的交易费。

### 3. 隐私工具：密钥派生互通、Nulo 钱包、Privacy Pools v2
**发生了什么**
- [Kassandra：公开 Tornado Cash 与 Privacy Pools V1 的助记词派生方案](https://x.com/kassandraETH/status/2118037514061750720) 00:47，这就是 kohaku-cli 和 Ambire 钱包能从同一助记词找到相同隐私协议记录的原因。[kohaku-cli 已更新到 v0.1.5](https://x.com/kassandraETH/status/2118310181993885759) 18:51，她呼吁把隐私原语用在几乎所有 L1 操作上。
- [Aztec：Nulo 钱包上线 Chrome 和 Firefox](https://x.com/aztecnetwork/status/2118039435493376125) 00:55，开源，发送前显示每笔转账的隐私状态；可通过 Shield 把 ETH 和 USDC 桥入 Aztec。
- [EF：Privacy Pools v2 让用户能私下做公开地址能做的任何事](https://x.com/ethereumfndn/status/2118210449292329203) 12:15。
- [Magicians：基于 BLS12-381 的 Stealth ABBE，通过 4844 blob 广播私密合约状态](https://ethereum-magicians.org/t/stealth-abbe-over-bls12-381-zero-metadata-broadcast-of-private-contracts-encrypted-state-via-eip-4844-blobs/30282) 03:58 开帖。

**为什么重要**
- 隐私协议的记录能跨钱包恢复，用户就不会被锁死在某一个钱包里。现在想用：kohaku-cli 可用于 Tornado Cash、Railgun、Privacy Pools；Ambire 与 kohaku-cli 共用 Tornado Cash 和 Privacy Pools V1 的派生方案；Aztec 上用 Nulo。
